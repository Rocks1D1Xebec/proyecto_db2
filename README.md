# Proyecto Base de Datos II (DB2)

## 📌 Descripción y Enfoque
- **Materia:** Base de Datos II (DB2).
- **Enfoque de la defensa:** Supongo que la defensa estará fuertemente centrada en la base de datos (modelado, arquitectura, consultas, optimización y gestión), ya que es el núcleo de la materia.
- **Restricciones:** No hay restricciones sobre las tecnologías a utilizar (stack libre).

---

## 🚀 Infraestructura y Despliegue
El proyecto debe estar desplegado y accesible:
- **Web Service:** [Render](https://render.com/)
- **Base de Datos:** [Neon](https://neon.tech/) (PostgreSQL) o [Cloudflare D1](https://developers.cloudflare.com/d1/)
